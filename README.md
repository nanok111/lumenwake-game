You tell yourself you'll play one quick round. Then night is closing in, you’re two lights short, and suddenly you care about timing that pulse just right. Lumenwake is a compact offline arcade game where you steer a small ship, gather 12 lights, and try to bring them home before nightfall. WASD or arrows to steer; mouse to aim; Space or click to pulse.

## Run it

From the repository root, run:

```sh
node serve.ts
```

Then open `http://localhost:8080` in a desktop browser. Requires Node.js 22.18 or later.
