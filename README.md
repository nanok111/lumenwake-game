Lumenwake is a compact offline arcade game where you steer a small ship, gather 12 lights, and try to bring them home before nightfall. Aim with your mouse and pulse with Space or click.

## Run it

From the repository root, run:

```sh
node serve.ts
```

Then open `http://localhost:8080` in a desktop browser. Requires Node.js 22.18 or later.
